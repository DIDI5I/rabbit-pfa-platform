# Stage 11A Goal

The goal of Stage 11A was to move Rabbit from a read-only chatbot into a safe workflow assistant.

Before Stage 11A:

```text
The chatbot could read, explain, summarize, and navigate.
```

After Stage 11A:

```text
The chatbot can prepare a write action, store it as pending, ask for confirmation, then execute only after the user confirms.
```

The first supported domain was notifications because it is low-risk and easy to verify.
