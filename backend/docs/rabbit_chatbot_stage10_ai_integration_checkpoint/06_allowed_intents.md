# Allowed AI Intents

AI refinement is only allowed for complex explanation/intelligence intents:

```text
product_intelligence_snapshot
stock_intelligence_explanation
stock_intelligence_summary
stock_intelligence_dashboard_explanation
```

AI refinement is not used for:

```text
navigation
clarification
clarification_needed
entity_not_found
ambiguous_entity
permission denied
validation errors
missing parameter responses
simple counts
write-action confirmation prompts
security failure responses
```
