# Stage 11D Goal

The goal of Stage 11D was to complete the operational loop:

```text
RFQ accepted
→ draft purchase lot created
→ purchase lot finalized with costs
→ stock received
→ inventory updated
```

Stage 11D also added direct manual stock operations:

```text
stock IN
stock OUT
set stock to target quantity
```

These actions are high-risk because they directly affect inventory quantities, alerts, valuation, and operational decisions.
