# Registry and Permissions

Registered tools:

```text
stock_intelligence_summary
stock_intelligence_dashboard_explanation
```

Allowed roles:

```text
owner
```

Denied roles:

```text
guest
client
supplier
fournisseur
```

Reason:

The stock intelligence dashboard exposes internal business data:

```text
stock risk
priority distribution
estimated reorder value
data quality weaknesses
model distribution
reorder recommendations
```

This should remain owner-only.
