# Stage 9A Goal

The goal of Stage 9A is to expose order visibility through the controlled chatbot workflow.

The chatbot can now answer:

```text
show orders
show recent orders
show pending orders
show order 6
```

Only read-only visibility is implemented.

Write actions are not implemented:

```text
create order
update order status
cancel order
mark as shipped
```

These belong to the future write-action confirmation pipeline.
