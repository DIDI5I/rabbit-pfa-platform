# Flowchart Reference

This package includes the Rabbit Chatbot V1 controlled flowchart image:

```text
rabbit_chatbot_v1_controlled_flowchart.png
```

The flowchart represents:

- user/session identification
- role identification
- deterministic intent parsing
- API fallback only when needed
- operation type classification
- exact tool/resource selection
- permission and scope verification
- tool execution
- deterministic answer composition
- API answer fallback
- final security/result verification
- fail sequence
- navigation UX with previous page bubble
- backend response convention
